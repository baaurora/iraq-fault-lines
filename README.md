# Iraq Fault Lines

An interactive relationship web and timeline of the people and events behind the Iraq War, from the 1951 Iranian oil nationalization to the US withdrawal in 2011.

- Theme hubs (oil, Cold War, WMD, Kurds, Iran vs. Iraq, Israel, coups, terror) with dated events and the people tied to them
- Stakeholder motives for each event, death tolls and regime profiles for coups, and guided throughlines
- Every blurb cites a source, mostly declassified US records (FRUS, National Security Archive), UN resolutions, congressional reports and official investigations

Live site: https://baaurora.github.io/iraq-fault-lines/

## Editing

Content lives in `data.js`. The page code is in `index.html`. Run `python3 build.py` to regenerate `docs/index.html`, the single-file page GitHub Pages serves.
